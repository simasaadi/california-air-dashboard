# California Air Quality — Scientific Animated (Streamlit)

Four animated, meaningful charts from NO₂/CO monitoring data:

1. Composite Pollution Index — monthly animated map (NO₂+CO).
2. Monthly Correlation Structure — animated heatmap.
3. Regional Trends — animated by pollutant (North/Central/South).
4. 3D Exposure Surface — animated NO₂×CO density.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Put your data in the repo as `California_NO2_CO_Combined.csv` or use the sidebar uploader.
